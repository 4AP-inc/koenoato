# こえのあと — 公開情報

スマートフォン向けアプリ「こえのあと」について、外に公開する情報を置くリポジトリです。
アプリ本体のソースコードは含みません。

`docs/` の中身が、そのまま GitHub Pages で公開されます(公開元: `main` ブランチの `/docs`)。

## 構成

```
docs/
├── index.html          アプリの紹介(入口のページ)
├── privacy/
│   └── index.html      プライバシーポリシー
├── assets/
│   ├── site.css        全ページ共通の見た目
│   └── icon.png        アプリのアイコン
└── .nojekyll           GitHub Pages に、ファイルをそのまま配らせるための印
```

ページは、1つの話題につき1つのフォルダを作り、その中に `index.html` を置きます。
こうすると、URL が `…/koenoato/privacy/` のように拡張子なしの形になり、あとで中身の
作り方を変えても URL が変わりません。

## 今後足すページの置き場所

| 内容 | フォルダ |
|---|---|
| 利用規約 | `docs/terms/` |
| お問い合わせ・よくある質問 | `docs/support/` |
| お知らせ・更新の記録 | `docs/news/` |

## 公開される URL

- 入口: `https://4ap-inc.github.io/koenoato/`
- プライバシーポリシー: `https://4ap-inc.github.io/koenoato/privacy/`

プライバシーポリシーの URL は Google Play に登録するので、変えないでください。

## 書き換えるとき

- 見た目は `docs/assets/site.css` にまとめてあります。ページごとに書き足さないでください。
- 外部のフォントや解析の仕組みは読み込みません(閲覧した人の情報を外に送らないため)。
- プライバシーポリシーを改めたら、ページ内の「改定の記録」に日付と内容を書き足します。
